1. Leverage Index Formulation

Every delivery is assigned a dynamic Leverage Index (LI) defined by:

LI = Phase_Weight × Margin_Weight × Stage_Multiplier
  • Death Phase (Overs 16-20): Baseline 1.50x, scaling up to 2.20x in tight chases.
  • Playoff Weighting: 1.20x for Qualifiers/Eliminators, 1.30x for IPL Finals.
  • HP Threshold: LI ≥ 1.50 captures the top 30% most pressurized deliveries.

2. Empirical Bayes Shrinkage & Contextual Multipliers

To neutralize small-sample skew, all metrics are shrunken toward prior means:

Metric_shrunken = (N_balls / (N_balls + K)) × Metric_raw + (K / (N_balls + K)) × Prior_mean
  • Sample Penalty (K=50 balls): Eliminates one-innings wonders.
  • Opposition Tiering: 1.15x run scaling against 53 elite tagged bowlers.
  • Tailender Discount: 0.70x weight on wickets taken against batters #7–#11.
